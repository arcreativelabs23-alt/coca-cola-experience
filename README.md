# Coca-Cola Experience

Create a modern, premium landing page inspired by Coca-Cola for a UI/UX portfolio project.

Design Style:

- Bold and elegant

- Primary color: Coca-Cola red (#F40009)

- Secondary colors: white, black, and light gray

- Smooth animations and subtle hover effects

- Fully responsive for desktop, tablet, and mobile

Hero Section:

- Full-screen background with a stylish Coca-Cola bottle and splashing cola effect

- Large headline:

  "Open Happiness"

- Subheadline:

  "Experience the refreshing taste loved by millions around the world."

- Two CTA buttons:

  - Explore Products

  - Watch Commercial

Navigation:

- Logo (placeholder)

- Home

- Products

- Our Story

- Sustainability

- Contact

Products Section:

Display cards for:

- Coca-Cola Original Taste

- Coca-Cola Zero Sugar

- Diet Coke

- Sprite

- Fanta

Each card should have:

- Product image

- Short description

- Learn More button

Why People Love Coca-Cola:

Four feature cards with icons:

- Refreshing Taste

- Global Brand

- Quality Ingredients

- Shared Moments

Gallery Section:

A modern image grid showcasing bottles, cans, and lifestyle moments.

Testimonials:

Three customer review cards with profile photos.

Sustainability Section:

Highlight Coca-Cola's environmental initiatives with modern illustrations and statistics.

Newsletter Section:

Email subscription field with a bold red Subscribe button.

Footer:

- Social media icons

- Quick links

- Copyright

- Privacy Policy

- Terms of Use

Technical Requirements:

- Built with React and Tailwind CSS

- Modern typography

- Glassmorphism where appropriate

- Smooth scrolling

- Fade-in animations

- Rounded cards

- Accessible color contrast

- SEO-friendly structure

- Fast-loading performance
